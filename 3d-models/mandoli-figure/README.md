# 만돌이(Mandoli) 마스코트 피규어 — 3D 제작용 모델

보내주신 **v2fun.ai 원본 3D 파일(OBJ)**을 실제 3D 프린팅이 가능한 **1파트 솔리드 STL**로
가공했습니다. 사진을 보고 새로 만든 게 아니라 **원본 지오메트리 자체를 그대로 사용**했기
때문에 디테일(깃털, 조끼 리브, 방패 엠블럼, 표정 등)이 원본과 동일합니다. 이후 요청하신
대로 **뒤쪽 꼬리 깃털을 제거**하고, **색상 근사치를 입힌 컬러 버전**을 추가했습니다.

![preview](preview/hero.png)

## 이번 업데이트

1. **꼬리 제거** — 허리 뒤에서 튀어나온 꼬리 깃털 뭉치를 잘라내고, 잘린 자리는 다시
   완전히 밀폐되도록 표면을 재구성했습니다 (아래 STL은 워터타이트 유지).
2. **색상 수정** — 신발 뒤꿈치/back 쪽에 잘못 칠해져 있던 노란색을 제거했습니다(이제
   노란색은 신발 앞/옆쪽에만). 눈(검은 눈동자)을 추가했고, 정수리 크레스트의 파란
   영역을 작게 줄였고, 색 경계가 딱딱한 블록처럼 보이지 않도록 인접 정점끼리
   블렌딩(스무딩)을 적용했습니다.

**⚠️ 여전히 한계가 있습니다.** STL은 색상을 담을 수 없고, 보내주신 `material.mtl`이
참조하는 `texture_20250901.png` 원본 텍스처 파일 자체는 받지 못했습니다(채팅엔 미리보기
이미지만 표시되고 실제 파일 첨부는 없었음). 그래서 이 색상은 **사진 속 배치를 보고 부위별
좌표 기준으로 칠한 근사치**이지, 원본 텍스처를 그대로 입힌 것이 아닙니다. 방패 엠블럼의
세부 무늬, 눈동자의 정확한 하이라이트, 볼터치, 넥타이 등 작은 디테일은 정확한 위치를 알
수 없어 생략하거나 대략적으로만 반영했습니다. **사진과 "완전히 똑같게" 만들려면
`texture_20250901.png` 파일이 반드시 필요합니다** — 받으면 실제 텍스처를 입힌 버전으로
다시 만들어드릴 수 있습니다. 컬러 버전은 `stl/mandoli_figure_colored.glb` 파일로 별도
제공됩니다 (GLB는 색상을 담을 수 있는 포맷).

## 원본 파일의 문제와 처리 과정

v2fun.ai가 내보낸 원본 OBJ는 그 자체로는 3D 프린팅이 불가능한 상태였습니다: 약 300개의
서로 분리된 조각(깃털 하나하나, 손가락 하나하나 등)으로 구성되어 있고, **어느 조각도
완전히 밀폐(watertight)되어 있지 않았습니다.**

처리 과정 (`scripts/process_v2fun_source.py`):
1. 노이즈성 파편(10면 미만의 초소형 조각, 57개) 제거
2. **PyMeshLab의 균일 리샘플링(SDF 오프셋 기반)**으로 약 250개 조각을 하나의 완전히
   밀폐된 솔리드로 재구성
3. 좌표계를 Y-up(원본) → Z-up(3D 프린팅 표준)으로 회전, 발밑을 바닥(z=0)에 맞춤, 220mm로
   스케일 조정
4. 허리 뒤 꼬리 부분(경계 박스로 지정)의 면을 잘라낸 뒤, 같은 리샘플링 + PyMeshLab의
   구멍 메우기(hole-closing) 필터를 다시 적용해 절단면을 완전히 재밀폐
5. 부위별 좌표 기준으로 근사 색상을 입혀 컬러 GLB로 별도 저장

결과: **약 233,000개 삼각형, 완전 밀폐 솔리드(`is_watertight = True`), 1파트, 꼬리 없음**.

## 포함된 파일

```
3d-models/mandoli-figure/
├── source/
│   ├── mandoli_v2fun_source.obj    # 보내주신 v2fun.ai 원본 OBJ (가공 전, 꼬리 포함)
│   └── material.mtl                 # 원본 머티리얼 정의 (텍스처 파일은 없음)
├── stl/
│   ├── mandoli_figure.stl           # 프린트용 STL (1파트, 220mm, 워터타이트, 꼬리 없음, 무채색)
│   └── mandoli_figure_colored.glb   # 컬러 미리보기/풀컬러 프린팅용 (근사 채색)
├── scripts/
│   └── process_v2fun_source.py      # 원본 OBJ -> STL/컬러 GLB 가공 스크립트
└── preview/
    └── hero.png                      # 렌더 미리보기 이미지 (컬러 버전)
```

## 실물 사양

| 항목 | 값 |
|---|---|
| 전체 높이 | 220 mm |
| 파츠 수 | 1개 (완전 밀폐 솔리드) |
| 삼각형 수 | 약 233,000개 |
| 워터타이트 여부 | `is_watertight = True` |

## 업체에 제작 의뢰 시 참고 사항

- **일반(단색) 3D 프린팅**: `mandoli_figure.stl`을 사용하세요. 완전히 밀폐된 단일
  솔리드라 추가 설명 없이 바로 견적/발주 가능합니다.
- **풀컬러 프린팅**(컬러 가능한 업체/프린터가 있다면): `mandoli_figure_colored.glb`를
  전달하세요. 단, 이 색상은 정교한 텍스처가 아니라 부위별 근사 색상이므로, 정확도가
  중요하다면 채팅에서 보내주신 원본 컬러 사진을 함께 전달해 업체가 참고하도록
  해주세요.
- 깃털 끝·손가락 등 얇고 돌출된 부분이 많아 서포트가 필요합니다. **레진(SLA/DLP)
  프린터**가 이런 세밀한 디테일을 살리기에 가장 적합합니다.
- 더 정확한 색상을 원하시면 `texture_20250901.png` 원본 텍스처 파일을 보내주세요 —
  받으면 원본 그대로의 텍스처를 입힌 버전으로 다시 만들어드릴 수 있습니다.

## 모델 재생성/수정하는 법

```bash
cd 3d-models/mandoli-figure/scripts
pip install numpy trimesh pymeshlab
python3 process_v2fun_source.py
```

`TARGET_HEIGHT_MM`으로 크기를, `CELLSIZE_PCT`로 디테일 대비 처리 속도를, `TAIL_BOX`로
잘라낼 꼬리 영역(최종 mm 좌표계 기준 x/y/z 범위)을 조정할 수 있습니다. `colorize()`
함수의 좌표 조건들을 바꾸면 색 배치도 다시 조정할 수 있습니다.
