# 만돌이(Mandoli) 마스코트 피규어 — 3D 제작용 모델

보내주신 만돌이 캐릭터(독수리/매 마스코트, 니트 조끼 + 반바지 + 운동화, 방패 엠블럼)를
바탕으로, 실제 3D 프린팅이 가능한 **1파트 솔리드 STL**을 만들었습니다. 컬러 참고 사진(정면·
후면·측면·클로즈업)을 추가로 보내주셔서, 머리를 감싸는 층상 깃털 갈기·눈썹·열린 부리·
어깨 퍼프·넥타이 등을 반영해 1차 버전보다 더 다듬었습니다.

![preview](preview/hero.png)

## ⚠️ 먼저 꼭 읽어주세요 — 이 모델의 한계

원본 이미지가 이미 완성된 3D 조각(아마도 Tripo 등 AI 툴로 만든 고polygon 스컬프트)이고,
**원본 3D 파일(OBJ/STL/GLB)은 없이 사진만** 가지고 있는 상황이라, 이번 모델은
**사진을 보고 제가 도형(구·캡슐·쐐기 등)을 조합해서 새로 만든 것**입니다.

즉:
- 얼굴 이목구비(부리·눈·볏), 옷(조끼+반바지), 날개손, 신발, 꼬리깃 등 **전체적인 실루엣과
  포즈는 원본과 비슷하게** 잡았지만,
- **원본만큼 정교한 조소(彫塑)적 디테일(얼굴 표정의 미세한 굴곡, 옷 주름, 손가락 깃털의
  섬세한 결 등)은 재현하지 못했습니다.** 훨씬 단순화·스타일화된 "귀여운 완구" 느낌의
  근사치입니다.
- 색상 정보는 STL에 담을 수 없으므로(형상만 저장), 실제 도색은 별도로 진행하셔야 합니다.

**더 원본에 가깝게 만들고 싶으시다면** 다음 중 하나를 추천드립니다:
1. 원본을 만든 곳(Tripo 등 AI 3D 생성 툴이나 제작 업체)에 원본 3D 파일을 요청
2. 이 이미지들을 3D 프린팅 업체나 피규어 조각가에게 직접 의뢰해 정식으로 스컬핑
3. 지금 이 모델을 초안/베이스로 삼아 Blender/ZBrush 등에서 디테일을 추가로 조각

## 포함된 파일

```
3d-models/mandoli-figure/
├── stl/
│   └── mandoli_figure.stl      # 완성 피규어 (1파트, 워터타이트 솔리드)
├── scripts/
│   └── generate_mandoli.py     # 이 모델을 만든 파라메트릭 생성 스크립트 (Python + trimesh)
└── preview/
    └── hero.png                 # 렌더 미리보기 이미지
```

## 실물 사양

| 항목 | 값 |
|---|---|
| 전체 높이 | 220 mm (요청하신 대로 넉넉하게 큰 사이즈로 설정) |
| 파츠 수 | 1개 (전신이 하나로 붙어있는 솔리드) |
| 워터타이트 여부 | 완전 밀폐 솔리드 (`is_watertight = True`) |
| 구성 | 머리(볏 2개+열린 부리+눈+눈썹+양쪽으로 늘어지는 층상 깃털 갈기), 몸통(조끼+넥타이+방패 엠블럼+어깨 퍼프), 팔 2개(한쪽은 얼굴 옆으로 든 포즈, 깃털 날개손), 다리 2개+운동화, 꼬리깃 |

## 업체에 제작 의뢰 시 참고 사항

- STL은 3D 프린팅 견적/발주에 가장 일반적인 표준 포맷입니다.
- 내부적으로 여러 도형을 겹쳐서 만든 뒤 하나로 합친 구조라, 일부 슬라이서에서는 "여러
  개의 겹친 셸(overlapping shells)"로 인식할 수 있습니다 — 이는 피규어류 3D 프린팅에서
  흔한 방식이며 대부분의 슬라이서가 자동으로 정리해서 출력합니다. 문제가 있다면 업체에
  "겹친 셸 구조, 자동 병합/repair 필요"라고 안내해주세요.
- 부리·볏·손가락(깃털) 등 얇고 돌출된 부분이 있어 서포트가 필요할 수 있습니다.
  **레진(SLA/DLP) 프린터**가 이런 디테일을 살리기에 적합합니다.
- 도색을 염두에 두고 계시다면, 사진 속 컬러 참고 이미지(흰색 몸통, 남색 조끼, 노란
  부리/신발 포인트 등)를 업체에 함께 전달해주세요.

## 모델 재생성/수정하는 법

```bash
cd 3d-models/mandoli-figure/scripts
pip install numpy trimesh shapely manifold3d
python3 generate_mandoli.py
```

`generate_mandoli.py`의 `TARGET_HEIGHT_MM` 값으로 전체 크기를 조정할 수 있고, `build()`
함수 안의 각 부위(머리 반지름, 팔 각도, 다리 길이 등) 숫자를 바꾸면 포즈·비율을 조정할
수 있습니다. 모든 치수는 mm 단위입니다.
