# DIY Smart Lamp — ESP32 + WS2812B NeoPixel

ESP32로 WS2812B 네오픽셀 스트립을 제어하는 Wi-Fi 스마트 스탠드 조명 프로젝트입니다.
스마트폰이나 PC 브라우저에서 웹페이지에 접속해 전원, 밝기, 색상, 효과(단색/따뜻한 백색/레인보우/호흡 효과)를 제어합니다.

## 준비물 (사용자 보유 기준)

| 부품 | 비고 |
|---|---|
| ESP32 개발 보드 (Type-C) | Wi-Fi 제어 + LED 구동 |
| WS2812B 네오픽셀 스트립 1m (60 LED/m) | 개별 제어 RGB LED |
| 점퍼 케이블 | 브레드보드 배선용 |
| 미니 브레드보드 | 저항/전원 분배 |
| USB-C 데이터 케이블 | ESP32 펌웨어 업로드/전원 |
| 5V USB 전원 어댑터 | LED 스트립 전원 (2A 이상 권장) |
| 금속 스탠드 자바라 파이프 | 조명 헤드 각도 조절용 지지대 |
| 반투명 아크릴판 (2mm) | LED 확산판(디퓨저) |

추가로 있으면 좋은 것: **330Ω 저항 1개**, **1000µF 전해 커패시터 1개** (둘 다 없어도 짧은 1m 스트립은 대부분 정상 동작하지만, 신호 안정성과 전원 보호를 위해 권장).

## 배선도

```
5V USB 전원 어댑터
   │
   ├── 5V ──┬──────────────► WS2812B 스트립 5V (전원선, 보통 빨간선)
   │        │
   │      (+) 1000µF 커패시터 (선택, 5V-GND 사이에 극성 주의하여 연결)
   │        │
   └── GND ─┴──────────────► WS2812B 스트립 GND (검정선)
                │
                └───────────► ESP32 GND (공통 접지 필수!)

ESP32 GPIO4 ──[330Ω 저항]──► WS2812B 스트립 DIN (데이터선, 보통 흰색/노란선)

ESP32는 USB-C 케이블로 별도 전원(PC 또는 다른 어댑터)을 공급하거나,
브레드보드의 5V 레일을 ESP32의 5V/VIN 핀에 연결해 어댑터 하나로 함께 전원을 공급해도 됩니다.
단, 이 경우 GND는 반드시 공통으로 연결되어야 합니다.
```

**핵심 규칙 3가지**
1. **공통 접지(Common Ground)**: ESP32의 GND와 LED 스트립의 GND, 전원 어댑터의 GND가 모두 연결되어 있어야 합니다.
2. **데이터선 저항**: GPIO4와 스트립 DIN 사이에 330Ω 저항을 직렬로 넣으면 신호 반사를 줄여 첫 LED가 깨지는 현상을 방지합니다.
3. **전원 용량**: 60개 LED가 전부 흰색 최대 밝기면 이론상 최대 약 3.6A까지 소모될 수 있습니다. 코드에서 `MAX_MILLIAMPS`로 소프트웨어 전류 제한을 걸어두었지만, 실제 사용하는 5V 어댑터의 정격 전류(A)에 맞춰 `src/main.cpp`의 `MAX_MILLIAMPS` 값을 반드시 수정하세요.

## 조립 순서

1. **디퓨저 만들기**: 아크릴판(2mm)을 램프 헤드 크기에 맞게 자르고(아크릴 커터 또는 톱 사용, 필요시 모서리는 사포로 마감), LED 스트립을 아크릴판 뒤쪽에 부착합니다(양면테이프/글루건). 빛이 아크릴을 통과하며 은은하게 퍼집니다.
2. **자바라 파이프 고정**: 금속 자바라 파이프 한쪽 끝에 LED+아크릴 헤드를 고정하고, 반대쪽 끝은 브레드보드/ESP32가 들어갈 받침대(베이스)에 고정합니다. 파이프 내부 또는 옆면을 따라 점퍼선을 정리해 배선합니다.
3. **회로 구성**: 위 배선도대로 브레드보드에 ESP32와 LED 스트립 전원/데이터선을 연결합니다.
4. **받침대 마감**: 브레드보드와 ESP32를 베이스 안에 고정하고, 5V 어댑터 케이블과 ESP32용 USB-C 케이블(또는 공통 전원)을 밖으로 뺍니다.

## 펌웨어 설정 및 업로드

### 1. Wi-Fi 정보 입력

`src/main.cpp` 상단의 사용자 설정 부분을 본인 환경에 맞게 수정하세요.

```cpp
const char *WIFI_SSID = "YOUR_WIFI_SSID";
const char *WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
#define MAX_MILLIAMPS 1500   // 실제 사용하는 5V 어댑터 정격 전류(mA)에 맞게 수정
```

### 2-A. PlatformIO로 업로드 (권장)

```bash
cd esp32-neopixel-smart-lamp
pio run -t upload      # 펌웨어 빌드 + 업로드
pio device monitor      # 시리얼 모니터로 IP 주소 확인
```

### 2-B. Arduino IDE로 업로드

1. Arduino IDE에 ESP32 보드 패키지 설치 (보드 매니저 → `esp32` 검색 후 설치)
2. 라이브러리 매니저에서 **FastLED** 설치
3. 보드: `ESP32 Dev Module` 선택, 포트: USB-C 연결 시 나타나는 포트 선택
4. `src/main.cpp` 내용을 `.ino` 파일로 복사해 업로드

### 3. 접속 확인

업로드 후 시리얼 모니터(115200bps)에 출력되는 IP 주소로 접속하거나,
`http://smartlamp.local` (mDNS 지원 기기)로 접속하면 제어 화면이 뜹니다.

## 기능

- **전원 On/Off**
- **밝기 조절** (5~255)
- **색상 선택** (RGB 컬러 피커)
- **모드**: 단색 / 따뜻한 백색(리딩 모드) / 레인보우 / 호흡 효과
- 마지막 상태를 ESP32 내부 플래시(Preferences/NVS)에 저장 → 재부팅해도 마지막 설정 유지

## 트러블슈팅

| 증상 | 원인/해결 |
|---|---|
| LED가 전혀 안 켜짐 | 공통 접지 확인, 5V/GND 극성 확인, DIN 방향(스트립에 화살표로 신호 방향 표시됨) 확인 |
| 첫 LED만 이상한 색 | GPIO4-DIN 사이 330Ω 저항 추가, 데이터선 길이 최대한 짧게 |
| 밝을 때 색이 틀어지거나 깜빡임 | 전원 어댑터 용량 부족 → `MAX_MILLIAMPS` 값을 실제 어댑터에 맞게 낮추거나 더 큰 어댑터 사용 |
| Wi-Fi 연결 안 됨 | SSID/PASSWORD 오타 확인, 2.4GHz 대역 Wi-Fi인지 확인(ESP32는 5GHz 미지원) |
| `smartlamp.local` 접속 안 됨 | 공유기/OS의 mDNS 미지원 가능 → 시리얼 모니터에 뜨는 IP 주소로 직접 접속 |

## 확장 아이디어

- 물리 버튼 추가: 여분 GPIO(예: GPIO15, 내부 풀업 사용)에 버튼을 연결해 Wi-Fi 없이도 On/Off 가능하도록 확장
- 사람 감지 센서(PIR) 연동으로 자동 점등
- Home Assistant/MQTT 연동으로 다른 스마트홈 기기와 통합
