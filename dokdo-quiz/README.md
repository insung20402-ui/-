# 🇰🇷 독도 수호 퀴즈 (독도 바로알기 행사용 웹앱)

교실·복도에서 휴대폰/태블릿/교실 TV로 바로 참여하는 독도 퀴즈 웹앱입니다. 설치 없이 링크(QR 코드)만 있으면 됩니다.

## 기능
| 화면 | 내용 |
|---|---|
| 홈 | 학년·반·번호·이름 입력 → **퀴즈 시작하기** / **📷 사진 퀴즈** |
| 독도 알기 | 독도의 가치 6가지, 핵심 숫자, 역사 연표 |
| 퀴즈 | **500문제** 중 매번 새 10문제. 쉬움 3(5점) + 보통 4(10점) + 어려움 3(15점) = **100점 만점**. 최근 푼 문제는 되도록 다시 안 나옴 |
| 사진 퀴즈 | 사진(이사부 동상, 독도 등대, 괭이갈매기 등)을 보고 맞히기. 문제당 10점 |
| 결과 | 점수·칭호, 행사 부스 **인증 코드**, 오답 노트 |
| 랭킹 | 반 대항전(학생별 최고 점수 합계) / 개인 TOP 20 (이름 가운데 글자는 가림) |
| 통계 (선생님) | 참여 횟수·평균·만점 수, **가장 많이 틀린/맞힌 문제 TOP 10 그래프**, 점수 분포, 시간대별 참여, 분야별 정답률, 반별 평균, **몇 시 몇 분에 누가 몇 점** 받았는지 기록표 |

## 파일
| 파일 | 설명 |
|---|---|
| `index.html`, `app.js` | 앱 화면과 동작 |
| `config.js` | 구글 시트 주소, 점수 구성, 제한 시간, 학년·반 수 |
| `questions.js` | 문제 500개 (자동 생성 파일) |
| `tools/build_questions.py` | 문제 생성기. 사실 목록을 고치고 `python3 tools/build_questions.py` 실행 |
| `photo-questions.js` | 사진 퀴즈 문제 20개 |
| `photos/` | 사진 퀴즈용 사진 넣는 곳 (파일 이름 목록: `photos/README.md`) |
| `apps-script/Code.gs` | 구글 시트에 결과를 저장하는 Apps Script |

## 1. 구글 시트(내 계정 Apps Script) 연결
1. 구글 드라이브 → 새 **구글 스프레드시트** 만들기 (예: "독도 퀴즈 결과")
2. 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여넣고 저장
3. 코드 맨 위 `ADMIN_KEY` 를 선생님만 아는 비밀번호로 바꾸고 저장 (웹앱 '통계' 화면 비밀번호)
4. **배포 → 새 배포 → 유형: 웹 앱** / 실행 사용자: **나** / 액세스: **모든 사용자** → 배포 → 권한 승인
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 `config.js` 의 `SCRIPT_URL` 에 붙여넣기

연결 후 스프레드시트에 자동으로 쌓이는 것:
- **results** 시트: 한 판마다 `시각(몇 시 몇 분 몇 초) · 학년 · 반 · 번호 · 이름 · 종류 · 점수 · 정답 수 · 걸린 시간`
- **문항별 기록** 시트: 문제 하나마다 `누가 · 어떤 문제를 · 맞혔는지(O/X)`
- 스프레드시트 메뉴 **독도 퀴즈 → 통계·그래프 새로고침** 을 누르면 **문항 통계** 시트에
  가장 많이 틀린/맞힌 문제 TOP 10 표와 막대그래프, 점수 분포 그래프가 만들어집니다.

> Code.gs 를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다.

## 2. 학생에게 배포
GitHub 저장소 → **Settings → Pages** → Branch 선택 후 저장 →
`https://<아이디>.github.io/<저장소>/dokdo-quiz/` 주소를 QR 코드로 만들어 교실·복도·학급 단톡방에 공유하세요.

## 3. 사진 퀴즈 사진 넣기
`photos/README.md` 의 파일 이름대로 사진을 `photos/` 폴더에 넣으면 그 문제가 자동으로 열립니다.
사진 출처는 `photo-questions.js` 의 `credit` 에 적어 주세요.
