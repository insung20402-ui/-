# 🇰🇷 독도 수호 퀴즈 (독도 바로알기 행사용 웹앱)

남학교 학생들이 **교실·복도에서 휴대폰/태블릿/교실 TV로 바로** 참여할 수 있는 독도 퀴즈 웹앱입니다.
설치 없이 링크(또는 QR 코드)만 있으면 됩니다.

## 구성
| 화면 | 내용 |
|---|---|
| 홈 | 학년·반·번호·닉네임 입력 → 퀴즈 시작, 게임 규칙 |
| 독도 알기 | 독도의 가치 6가지(역사·지리·경제·생태·지질·국제법), 핵심 숫자, 역사 타임라인 |
| 퀴즈 | 22문항 중 10문항 무작위 출제, 문제당 15초, O/X + 4지선다, 정답 해설 |
| 결과 | 점수·칭호, **행사 부스 인증 코드**, 오답 노트 |
| 랭킹 | **반 대항전**(참여 학생 최고 점수 합계) / 개인 TOP 20 |

### 남학생 참여를 끌어올리는 장치
- ⏱️ 제한 시간 + 빨리 맞히면 시간 보너스, 🔥 연속 정답 콤보 보너스 → 게임처럼 경쟁
- 🏫 **반 대항전**: 반 점수 = 참여 학생 점수 합계 → "우리 반 한 명이라도 더!" 참여 독려
- 👑 칭호(독도 수호 대장군 ~ 독도 새내기)와 재도전(최고 점수만 기록)
- 🎁 결과 화면의 **인증 코드**(`DD-학년반번호-XXXX`)를 등굣길 '독도 수호 마음 나누기' 부스에서 보여 주면 간식 지급 → 퀴즈와 오프라인 행사 연결

## 실행 방법
1. **바로 써 보기**: `index.html` 파일을 브라우저로 열면 됩니다. (결과는 그 기기에만 저장)
2. **학생 배포(추천)**: GitHub 저장소 → Settings → Pages → Branch 선택 후 저장하면
   `https://<아이디>.github.io/<저장소>/dokdo-quiz/` 주소가 생깁니다. 이 주소를 QR 코드로 만들어
   교실 게시판·복도 포스터·학급 단톡방에 공유하세요.

## 참여 결과 데이터베이스화 (구글 시트)
1. 새 구글 스프레드시트 → **확장 프로그램 → Apps Script**
2. `apps-script/Code.gs` 내용을 붙여넣고 저장
3. **배포 → 새 배포 → 웹 앱** (실행 사용자: 나 / 액세스: 모든 사용자) → URL 복사
4. `config.js`의 `SCRIPT_URL`에 붙여넣기

이후 모든 참여 기록이 `results` 시트에 한 줄씩 쌓이고(시간, 학년, 반, 번호, 닉네임, 점수, 정답 수, 최대 콤보, 소요 시간, 틀린 문항 번호),
랭킹 화면은 전교 기록으로 표시됩니다. Apps Script에서 `buildWrongStats` 함수를 실행하면 **가장 많이 틀린 문항 통계**가 만들어져
행사 판넬 자료로 쓸 수 있습니다.

## 문제 수정
`questions.js`에서 문항을 추가·수정하면 됩니다. (`type`: `ox`/`mc`, `level`: 1~3, `exp`: 해설)
학년·반 수, 문제 수, 제한 시간은 `config.js`에서 바꿀 수 있습니다.
